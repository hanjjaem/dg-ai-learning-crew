01

GitHub 회원가입 (1분 컷)

STEP 1-1

공식 웹사이트 접속

브라우저에서 github.com에 접속한 뒤 우측 상단 [Sign up] 클릭

STEP 1-2

이메일 & 계정 정보 입력

자주 쓰는 이메일(구글 메일 등) 입력 ➡️ 비밀번호 설정 ➡️ 원하는 영문 아이디(Username) 입력

STEP 1-3

인증코드 확인 & 완료

이메일함으로 도착한 6자리 보안 번호를 입력하면 즉시 가입 완료!

02

GitHub CLI (`gh`) 설치 방법 (Windows)

GitHub CLI는 깃허브 웹사이트에 접속하지 않고도 터미널 명령어만으로 저장소 생성, PR, 이슈 관리를 할 수 있는 공식 도구입니다.

🚀 가장 추천하는 빠른 방법 10초 완료

Windows 패키지 매니저로 한 줄 설치

윈도우 PowerShell(또는 터미널)을 열고 아래 명령어를 붙여넣고 엔터를 치면 끝납니다:

winget install --id GitHub.cli
설치 파일 다운로드 방식

공식 웹사이트에서 설치 파일 받기

1. 공식 다운로드 페이지 cli.github.com 접속
2. [Download for Windows] 버튼 클릭
3. 다운로드된 `.msi` 설치 파일을 실행하고 [Next]만 누르면 설치 완료!

03

환경설정 & 브라우저 간편 로그인 (`gh auth login`)

설치가 끝났다면, 딱 한 번만 내 깃허브 계정과 터미널을 연결해 주면 영구적으로 자유롭게 쓸 수 있습니다.

PowerShell 또는 터미널에 아래 명령어 입력:
gh auth login

터미널에 질문이 나오면 순서대로 아래처럼 선택하세요:

1. ? What account do you want to log into? ➡️ GitHub.com (엔터)

2. ? What is your preferred protocol for Git operations? ➡️ HTTPS (엔터)

3. ? Authenticate Git with your GitHub credentials? ➡️ Yes (엔터)

4. ? How would you like to authenticate GitHub CLI? ➡️ Login with a web browser (엔터)

🎉 마지막 1초: 화면에 일회용 8자리 코드(예: 1234-ABCD)가 뜹니다.
엔터를 누르면 인터넷 창이 뜨는데, 코드를 붙여넣고 [Authorize github] 버튼만 누르면 로그인 끝!

⚡️ 오늘 우리가 사용한 "마법의 깃허브 원터치 3줄 명령어"

Pro Tip

이제 프로젝트를 만들었을 때, 웹사이트에 들어가서 버튼을 누를 필요 없이 아래 3줄만 실행하면 원격 저장소 생성부터 푸시까지 3초 만에 끝납니다:

1.
git init # 내 컴퓨터 폴더를 깃 저장소로 초기화
2.
git add . && git commit -m "feat: 첫 프로젝트 완성" # 모든 코드를 사진 찍듯 스냅샷 커밋 생성
3.
gh repo create 내프로젝트명 --private --source=. --remote=origin --push # 깃허브에 비공개(private) 저장소를 만들고 코드를 원격에 즉시 푸시!
