# Antigravity Agent Control & Coding Rules (v2.0)

## Core Principles
1. Vision: Completely replace KakaoTalk room submissions with an independent PC-first AI Prompt Knowledge Hub.
2. Desktop-First Wide Dashboard: Design for 1200px~1920px PC work environments (Notion/Slack style) while maintaining full mobile responsiveness.
3. 3-Second Share Link Workflow: Support official ChatGPT/Claude/Gemini share URLs with auto-detection and zero friction.
4. Prompt Reusability: Always provide 'Copy Prompt' and 'Open Conversation' for peer learning.
5. Strict TypeScript & Pure Functions: No `any`. Calculation and URL parsing in `src/lib/calculations.ts`.
6. Verify Before Done: Run build/lint check to ensure 0 errors.
