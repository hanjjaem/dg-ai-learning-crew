Overview

KorDoc AI는 무엇인가요?

KorDoc AI는 글을 쓰고 생각하는 AI(LLM)가 아닙니다. AI가 음식을 먹기 전, 체하지 않도록 복잡한 한글 공문서의 가시와 껍질을 완벽하게 발라내어 주는 '전문 파서(Parser)'입니다.

How to use

어떻게 쓰나요? 딱 3단계입니다

복잡한 개발 툴 설치는 필요 없습니다. 클릭 몇 번으로 바로 실무에 적용하세요.

1
최초 1회, 배치 파일 더블클릭
배포 폴더의 1_설치하기(더블클릭).bat 파일을 실행합니다. 변환 엔진(Node.js LTS)과 앱이 백그라운드에서 전자동으로 설치됩니다.
🖱️ 1_설치하기(더블클릭).bat 실행
2
문서를 마우스로 끌어다 놓기
KorDoc AI를 띄운 뒤 변환할 HWPX 문서를 마우스로 끌어다 넣습니다. 깨끗한 .md 파일이 완성됩니다.
3
정제된 마크다운을 AI에 입력
완성된 .md 텍스트를 복사해 ChatGPT나 사내 AI에 넣습니다. 문서 구조와 표 관계가 살아 있어 분석과 요약에 활용하기 좋습니다.
