# KorDoc AI 설치 안내

AI 러닝크루 실습용 KorDoc AI 설치 자료입니다.

## 인터넷 연결이 가능한 PC

1. `1_설치하기(더블클릭).bat` 파일을 내려받습니다.
2. 파일을 더블클릭합니다.
3. 관리자 권한 확인창이 뜨면 **예**를 누릅니다.
4. Node.js와 KorDoc AI가 자동으로 설치되고 KorDoc AI가 실행됩니다.

설치 배치파일은 KorDoc AI가 PC에 없으면 공식 GitHub 릴리스의 **KorDoc AI v1.5.1 MSI**를 자동으로 내려받아 설치합니다.

- 공식 MSI: https://github.com/chrisryugj/kordoc-ai/releases/download/v1.5.1/KorDoc.AI_1.5.1_x64_ko-KR.msi
- KorDoc AI 프로젝트: https://github.com/chrisryugj/kordoc-ai

## 인터넷이 제한된 PC

오프라인 설치가 필요한 경우 `KorDoc.AI_1.5.1_x64_ko-KR.msi` 파일을 설치 배치파일과 **같은 폴더**에 둔 뒤 배치파일을 실행합니다. 배치파일은 같은 폴더의 `KorDoc*.msi`를 우선 사용하도록 구성되어 있습니다.

> 첨부된 통합설치 패키지에는 MSI가 포함되어 있지만, 이 저장소의 현재 자동 업로드 경로에는 대용량 바이너리를 직접 넣지 않았습니다. 인터넷 가능한 교육장 PC에서는 배치파일 하나만으로 설치할 수 있습니다.
