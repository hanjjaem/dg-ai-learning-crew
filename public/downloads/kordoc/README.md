# KorDoc AI 설치 안내

AI 러닝크루 실습용 KorDoc AI 설치 자료입니다.

## 가장 쉬운 설치: 통합설치 ZIP

GitHub Release에서 **KorDoc AI 통합설치 패키지 v1.5.1**을 내려받아 압축을 푼 뒤 `1_설치하기(더블클릭).bat`을 실행하면 됩니다.

- 통합설치 패키지: https://github.com/hanjjaem/dg-ai-learning-crew/releases/tag/kordoc-package-v1.5.1

ZIP 구성:

- `1_설치하기(더블클릭).bat`
- `2_제품안내서_열어보기.html`
- `KorDoc.AI_1.5.1_x64_ko-KR.msi`

## 인터넷 연결이 가능한 PC

1. `1_설치하기(더블클릭).bat` 파일을 실행합니다.
2. 관리자 권한 확인창이 뜨면 **예**를 누릅니다.
3. Node.js와 KorDoc AI가 자동으로 설치되고 KorDoc AI가 실행됩니다.

설치 배치파일은 KorDoc AI가 PC에 없으면 공식 GitHub 릴리스의 **KorDoc AI v1.5.1 MSI**를 자동으로 내려받아 설치합니다.

- 공식 MSI: https://github.com/chrisryugj/kordoc-ai/releases/download/v1.5.1/KorDoc.AI_1.5.1_x64_ko-KR.msi
- KorDoc AI 프로젝트: https://github.com/chrisryugj/kordoc-ai

## 인터넷이 제한된 PC

통합설치 ZIP에는 MSI가 함께 들어 있으므로 압축을 푼 뒤 배치파일을 실행하면 로컬 MSI를 우선 사용합니다. 배치파일은 같은 폴더의 `KorDoc*.msi`를 먼저 찾아 설치하도록 구성되어 있습니다.
