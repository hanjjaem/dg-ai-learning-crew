기획 01 · 문제 정의 (Why?)

"카카오톡 단톡방 인증은 왜 실패하는가?"

🎯 기획자의 문제 의식: "단톡방에 인증 캡처 사진이 쏟아지면 좋은 프롬프트가 다 묻히고, 내 업무에 재활용할 수도 없다. 게다가 총무는 매일 밤 엑셀 켜놓고 누가 냈는지 눈알 빠지게 체크해야 한다."

대부분의 프로젝트는 "무엇을 만들까?"부터 시작해서 망합니다. 기획자는 "지금 무엇이 가장 고통스러운가?"를 먼저 정의해야 합니다. 우리의 목표는 단톡방을 돕는 보조 도구가 아니라, 카톡 인증 자체를 완전히 없애버리는 것이었습니다.

💡 기획 포인트: 기술보다 중요한 것은 '풀고자 하는 고통의 명확한 정의'입니다.
기획 02 · 3대 사용자 경험(UX) 원칙 수립

"3초 컷 무마찰 인증 & PC 데스크톱 최우선"

📐 기획자가 세운 3대 불변의 원칙: 1. 3초 컷 무마찰 (Zero Friction): 복잡한 사진 업로드 X, Share 링크 붙여넣기만 하면 AI 도구 자동 감지 후 1초 완료
2. 데스크톱 와이드 (Desktop-First): 듀얼 모니터 PC에서 일하는 공무원을 위한 1200~1920px 화면
3. 지식 자산화 (Knowledge Hub): 동료 프롬프트 원클릭 복사 및 실무 즉시 적용

인증 절차가 10초만 넘어가도 공무원들은 참여를 포기합니다. "복사해서 붙여넣으면 끝난다"는 절대적인 편리함을 기획의 1순위로 못 박았습니다.

💡 기획 포인트: 사용자가 참여할 수밖에 없는 '초저항(Zero Friction)' 환경을 설계하세요.
기획 03 · AI를 통제하는 헌법 (AGENTS.md)

"AI가 헛소리 못 하게 규칙 문서를 먼저 쥐어줘라"

📜 AGENTS.md (에이전트 행동 지침서): - 비전 통제: 카카오톡 단톡방 완전 대체 및 독립형 AI 지식 허브 지향
- UI 통제: 1200px 와이드 데스크톱 기본, 과도한 섀도우 배제
- 품질 통제: 코드 수정 후 반드시 `npm run build` 자체 검증

AI에게 매번 긴 설명을 반복하면 지치고 AI도 기억을 잃어버립니다. 프로젝트 최상단에 `AGENTS.md`라는 행동 규범 파일을 박아두면, AI는 모든 질문과 코드 작성 시 이 규칙을 최우선 법률령으로 복종하게 됩니다.

💡 기획 포인트: AI에게 일 시키기 전, '프로젝트 규칙 문서'를 먼저 작성하는 것이 일류 기획자입니다.
구현 01 · 과감한 쳐내기 (Focus & Cut)

"드롭다운 기능은 왜 있어야 될까? 단일화해."

🗣️ 실제 지시 프롬프트: "드롭다운 기능은 왜 있어야 될까? 단일화해. 헤더를 꾸미지 말고 구조적으로 분리해라. 1px 라인만 쓰고 그림자는 빼."

개발자가 편하자고 넣어둔 15명 전환 스위처와 과도한 입체 그림자를 기획자가 단칼에 잘라냈습니다. 군더더기 기능을 뺄수록 동료들이 오래 켜두어도 피로하지 않은 단정한 명품 툴이 됩니다.

💡 실습 포인트: "이 기능 진짜 필요해?"라고 끊임없이 의심하고 쳐내세요.
확장 02 · 사내 기존 자산(코드) 재활용

"공모전 폴더 참고해서 이미지 어떻게 올렸는지 확인해봐"

🗣️ 실제 지시 프롬프트: "프롬프트뿐만 아니라 생성한 그림, HTML도 전시했으면 좋겠어. D:\work\동구_공모전\app 이 폴더 참고해서 이미지 어떻게 올렸는지 확인해볼래?"

새로운 기능을 만들 때 AI에게 막연히 "업로드 만들어줘" 하면 엉뚱한 기술을 씁니다. 구청 안에 이미 잘 만들어진 공모전 프로젝트 경로를 던져주자, 검증된 이미지 스토리지와 모달 UI를 10초 만에 완벽히 흡수했습니다.

💡 실습 포인트: 맨땅에 헤딩하지 말고, 사내에 이미 존재하는 레퍼런스 폴더를 AI에게 가리키세요.
디버깅 03 · 말보다 빠른 캡처 1장 투척

"이게 뭐야? 모달이 내부에 파묻혀 있잖아. 재진단해!"

🗣️ 실제 지시 프롬프트: "이게 뭐야 상세 모달로 열려야 하는거 아니야? (화면 캡처 첨부) 아니 모달이 내부에 파묻혀있잖아. 재점검 해봐 재진단!"

모달 상단이 화면 밖으로 잘리는 복잡한 CSS 버그가 터졌습니다. 기획자는 기술 용어를 쓸 필요가 없습니다. 화면 캡처 한 장을 던지며 "파묻혔잖아!"라고 지적하자, AI가 부모 박스 갇힘 현상을 알아채고 React Portal로 화면 전체를 장악하게 고쳐냈습니다.

💡 실습 포인트: 에러 설명하려 애쓰지 마세요. 스크린샷 1장이 천 마디 말보다 빠릅니다.
UX 고도화 04 · 사용자 주도권 확립

"버튼 말고 행을 눌러도 튕기는데 이게 맞아? 버튼을 눌러야지."

🗣️ 실제 지시 프롬프트: "아카이브에서 마우스 클릭하면 외부 링크로 연결되는 부분이 뭐뭐있어? 버튼 말고 행 전체를 눌러도 이동하는데 이게 맞아? 특정 버튼을 눌러야 이동시켜야지."

텍스트를 복사하려 행을 눌렀는데 갑자기 ChatGPT 사이트로 튕겨나가는 나쁜 UX를 날카롭게 잡아냈습니다. "행 클릭 = 내부 상세 모달" vs "`[ ↗ ]` 버튼 클릭 = 외부 사이트 이동"으로 명확히 분리하여 사용자 통제권을 완성했습니다.

💡 실습 포인트: 사용자가 의도하지 않은 강제 화면 이동을 원천 차단하세요.
실전 런칭 05 · 관리자 관점 역질문 & 8만원 실데이터

"관리자 입장에서 부족한 부분 없어? 실데이터 8만원 반영해."

🗣️ 실제 지시 프롬프트: "관리자 입장에서 부족한 부분 없어? 초기 회비 8만원으로 수정. 김남희 등 8명 입금완료 처리. 이현아 복지정책과로 수정. 깃허브에 올려줘."

"관리자 입장에서 부족한 게 뭐지?"라는 역질문으로 출장 면제, 회비 장부, 공휴일 벌금 제외, 개인정보 블라인드 4대 방어막을 챙겼습니다. 그리고 가짜 데이터를 지우고 실제 16명 크루원 명단과 8명 완납(640,000원, 50%) 실데이터를 주입하여 런칭했습니다.

💡 실습 포인트: "운영자 입장에서 빠진 게 뭐야?"라고 AI에게 되물어보세요. 엣지케이스를 다 찾아냅니다.
