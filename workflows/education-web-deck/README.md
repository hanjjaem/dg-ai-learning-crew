# 교육주제 → 시나리오 → 웹 발표자료

주제를 주면 에이전트가 바로 완성안을 내는 방식이 아닙니다. 짧은 인터뷰로 대상·목표·시간·현장 사례를 함께 정하고, 1차 시나리오를 같이 고친 뒤 승인된 내용으로 HTML 발표자료를 만듭니다. 별도 AI API 설정은 필요하지 않습니다.

## 이렇게 시키세요

이 저장소를 연 에이전트 채팅에 아래 문장을 입력합니다.

```text
workflows/education-web-deck/SKILL.md를 읽고 실행해줘.
교육주제: AI를 활용해서 업무 보고서 초안 만들기
```

이렇게 주제만 입력하면 에이전트가 먼저 **누가 듣는지**부터 한 질문씩 인터뷰합니다. 답할 때마다 지금까지 정해진 교육 설계와 다음 선택을 보여줍니다.

```text
대상: AI를 처음 쓰는 공무원
시간: 90분
교육 후 결과물: 내 업무에 쓸 보고서 초안과 검토 기준
실습 방식: 직접 명령어를 치지 않고 에이전트에게 시키기
스타일: 슈카월드처럼 큰 키워드, 질문과 비유가 있는 강연형
```

`기획만 해줘`를 붙이면 강의 시나리오까지 만듭니다. `이어서 웹 발표자료까지 만들어줘`로 이어갈 수 있습니다.

대답이 어려우면 `추천해줘`라고 하면 됩니다. 빨리 초안을 보고 싶으면 `나머지는 추천해서 1차안 보여줘`라고 말합니다. 에이전트는 추천한 부분을 가정으로 표시합니다.

## 진행 과정

| 단계 | 에이전트가 하는 일 | 남는 파일 |
|---|---|---|
| 인터뷰 | 한 번에 한 질문으로 대상·결과물·시간·환경·사례 결정 | 대화 설계판 |
| 1차안 | 답변을 brief와 시간표·강사 멘트·실습에 반영 | brief.md, scenario.md |
| 함께 수정 | 핵심 선택을 묻고 답변에 따라 시간표와 장면 갱신 | scenario.md |
| 슬라이드 구성 | 한 장 한 메시지와 화면 배치 결정 | deck.json |
| 제작 | 발표 기능이 포함된 단일 HTML 생성 | index.html |
| 검증 | 내용·시간·화면·조작 점검, 오류 수정 | qa.md |

산출물은 기본적으로 `workshops/<주제>/`에 저장됩니다. 생성된 `index.html` 하나를 더블클릭하면 발표할 수 있습니다. 교육에서 외부 AI 서비스나 자료 링크를 사용할 때는 인터넷이 필요합니다.

발표 조작: `←` `→` `Space` 이동, `O` 전체보기, `N` 노트, `F` 전체화면, `?` 도움말. **노트는 현재 화면에 표시되므로 화면 공유 시 청중에게도 보입니다.**

## ChatGPT 웹에서 인터뷰부터 시작하기

[복사해서 쓰는 인터뷰 프롬프트](prompts/chatgpt-planner.md)를 ChatGPT에 넣고 주제만 바꿉니다. ChatGPT와 질문을 주고받으며 시나리오를 확정한 뒤, 마지막 실행 지시문을 이 저장소를 연 에이전트에게 전달합니다.

## 다른 PC에서 이어가기

이 `workflows/education-web-deck/` 폴더와 수정할 `workshops/` 자료를 저장소에 함께 보관합니다. 다른 PC에서 clone/pull한 뒤 에이전트에게 같은 실행 문장을 전달하면 됩니다. `.agents` 폴더나 개인 PC의 전역 스킬 설치를 전제로 하지 않습니다. 현재 패키지는 **파일 경로로 실행하는 저장소용 워크플로우**이며 `$education-web-deck` 자동 호출이 설치됐다고 가정하지 않습니다.

제작에는 Node.js 20 이상이 필요합니다. 완성 HTML 열람에는 Node.js가 필요하지 않습니다. 기존 앱이나 발표본의 배포 주소 변경은 별도 요청으로 진행합니다.

## 에이전트용 생성 명령

사용자가 직접 칠 필요는 없습니다. 다음은 에이전트가 사용하는 명령입니다.

```text
node workflows/education-web-deck/scripts/render-deck.mjs workshops/<주제>/deck.json --check
node workflows/education-web-deck/scripts/render-deck.mjs workshops/<주제>/deck.json workshops/<주제>/index.html
```

에이전트가 출력 폴더를 먼저 만든 뒤 실행합니다. 기존 HTML 재생성은 대상 확인 후 `--force`를 덧붙입니다. 내용 수정은 JSON, 공통 디자인·발표 기능 수정은 `assets/deck-shell.html`과 생성 스크립트에서 합니다.

렌더러가 실제로 만드는 화면은 [예제 원본](examples/example-deck.json)과 생성된 `examples/example-deck.html`에서 확인할 수 있습니다.

렌더러 변경 뒤에는 에이전트가 `node workflows/education-web-deck/scripts/smoke-test.mjs`로 예제 구조, 시간 합계, 입력값 방어와 오프라인 의존성을 확인합니다.

## 연결한 기존 기법

`slides`의 Workshop Training 전략에서 목표·아젠다·개념과 실습·종합·자료·Q&A 흐름을 참고했습니다. 설치된 슬라이드 검색 스크립트는 있으면 사용하고, 없으면 포함된 콘텐츠 규격과 템플릿으로 실행합니다. 기본 템플릿은 고대비 다크 강연형이며, 다른 스타일은 제작 시 지시할 수 있습니다.
